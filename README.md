# Snake in C
A project I've started to get more comfortable with programming in C\
Uses Raylib

![snake_preview](./assets/snake.png "Snake preview")
![title_screen](./assets/title.png "Titlescreen")

# How to run
currently you can make it yourself by running:\
'make run' in the root dir

# Known bugs
- Input handling -> When spamming multiple inputs inbetween moves you can make illegal moves or accidentally die
- Apple spawning -> Currently apple only blacklists the snake head as an undesired spawn so it can still spawn in the body
- Resizing -> Haven't implemented any resize managing so expect to break the game
